Two Kids Design is a modern, responsive digital marketplace for high-quality print-ready designs. 
The website allows customers to browse, discover, and purchase creative digital artwork for T-shirts, hoodies, mugs, tote bags, stickers, and other print-on-demand products.
The project is built as a static website using HTML, CSS, Bootstrap, and JavaScript, providing a fast, user-friendly experience across desktop, tablet, and mobile devices.
